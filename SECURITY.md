# Security

Report vulnerabilities privately to [harlan@harlanzw.com](mailto:harlan@harlanzw.com).
Include the affected version, impact, and a minimal reproduction.
Remove access tokens, refresh tokens, client secrets, and private Site data.

Security fixes target the latest published package version.
Upgrade to that version before confirming whether a reported issue still occurs.

For ordinary bugs and feature requests, use [GitHub issues](https://github.com/harlan-zw/gscdump/issues).
