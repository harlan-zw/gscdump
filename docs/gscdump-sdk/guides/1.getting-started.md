# Getting started

Choose the package by where your application reads data.

| Your application needs | Install | Import |
| --- | --- | --- |
| Direct Google Search Console or Bing Webmaster calls | `gscdump` | `gscdump` or `gscdump/bing` |
| Hosted gscdump data and partner integrations | `@gscdump/sdk` | `@gscdump/sdk/v1` |

`@gscdump/sdk` depends on `gscdump` for shared helpers.
It adds hosted clients; it does not re-export the direct Google and Bing clients.
If your code imports both packages, declare both as dependencies.

## Call Google directly

```bash
pnpm add gscdump
```

```ts
import { googleSearchConsole } from 'gscdump'

const google = googleSearchConsole({ accessToken: process.env.GOOGLE_ACCESS_TOKEN! })
const sites = await google.sites()
```

You manage Google credentials and store any data you want to keep.
Continue with [Direct search clients](./2.direct-clients.md).

## Read hosted data

```bash
pnpm add @gscdump/sdk
```

```ts
import { createGscdumpV1Client } from '@gscdump/sdk/v1'

const hosted = createGscdumpV1Client({
  credential: () => process.env.GSCDUMP_API_KEY!,
})

const lifecycle = await hosted.getUserLifecycle({
  params: { userId: 'u_01' },
})
```

Run this code on your server. Keep the gscdump credential out of browser bundles.
Continue with [Hosted integrations](./3.hosted-integrations.md).

For terminal commands and agent setup, use the [CLI guide](../../gscdump-cli/guides/1.getting-started.md).
