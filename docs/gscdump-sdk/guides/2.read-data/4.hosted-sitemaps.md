# Check sitemap membership and changes

Sitemap membership describes an observed feed generation. It does not prove that a Search Engine indexed a URL.

## Before you start

Use `sitemaps:read` for an authorized Site. The [hosted first-result guide](/gscdump-sdk/guides/start/hosted-first-result) shows client setup.

## Read Site sitemaps

```ts
const snapshot = await client.getSiteSitemaps({ params: { siteId } })
console.log(snapshot.data.sitemaps, snapshot.data.generation)
```

Read `snapshot.data.generation` and `snapshot.data.meta.syncStatus` with the feed list. No generation means the Site has no published membership observation yet.

## Inspect one Sitemap

For one exact Sitemap, use `client.inspectSiteSitemap({ params: { siteId }, query: { searchEngine: 'google', url } })`.
Google reads that Sitemap live through the platform, using Google's API quota without spending URL Inspections.
Bing reads dated stored evidence. Quote `capture.source` and `capture.capturedAt` with the answer.
`unavailable` never proves absence. Other Sitemap reads use the hosted record.

## Check URL membership

```ts
const membership = await client.querySitemapMembership({
  params: { siteId },
  body: { urls: ['https://example.com/docs'] },
})
console.log(membership.data.evidence)
```

The response uses `present`, `absent`, or `unknown` evidence for each exact URL. An `unknown` result can reflect a missing or incomplete generation. Do not turn it into `absent`.

## Read changes

```ts
const changes = await client.getSiteSitemapChanges({
  params: { siteId },
  query: { days: 28 },
})
console.log(changes.data.added, changes.data.removed, changes.data.completeness)
```

Check the window and `completeness` before reporting a removal. See the [hosted HTTP contract](/gscdump-sdk/api/hosted-http) for pagination and optional fields.

## Handle incomplete observations

If generation or completeness is missing, show “unknown” and retry after a new observation. For URL inspection rather than feed membership, read [Hosted indexing](/gscdump-sdk/guides/read-data/hosted-indexing). [Webhooks](/gscdump-sdk/guides/build-integrations/webhooks) can notify your server of later changes.
