# Read saved Indexing Evidence for a Site

Indexing Evidence is a dated Search Engine observation. It is not a permanent URL verdict.

## Before you start

Use a key with `indexing:read` and an authorized Site. The main path below only reads saved data. Start with the [hosted client](/gscdump-sdk/guides/start/hosted-first-result#make-the-request).

## Read the Site view

```ts
const overview = await client.getSiteIndexing({
  params: { siteId },
  query: { days: 28 },
})
console.log(overview.data.summary, overview.data.trend)
```

The summary includes URL counts and observation dates. Check `oldestCheck` and `newestCheck` before using a trend. The [hosted HTTP reference](/gscdump-sdk/api/hosted-http) defines the full response.

## List URLs and diagnostics

`listSiteIndexingUrls` returns saved URL observations. `getSiteIndexingDiagnostics` explains coverage and missing evidence. Keep the observation date next to each URL in your UI. If a URL has no saved observation, show that gap rather than an indexed or unindexed claim.

## Request a fresh inspection if needed

`inspectSiteUrls` starts a new inspection and requires `indexing:write`. It is a mutation. A network timeout leaves its outcome uncertain, so read saved state before sending it again. [Errors and retry](/gscdump-sdk/guides/operate/errors-and-retry) covers this case.

## Choose another source

[Hosted sitemaps](/gscdump-sdk/guides/read-data/hosted-sitemaps) answers whether an exact URL appears in a saved sitemap generation. That is separate evidence. To call Bing directly, switch to [Direct Bing](/gscdump-sdk/guides/read-data/direct-bing).
