# Start with the SDK

Choose where data comes from. A direct client calls Google or Bing with your Search Engine credential. A hosted client reads gscdump data with a server-held API key.

| Need | Guide |
| --- | --- |
| Compare the paths | [Choose access](/gscdump-sdk/guides/start/choose-access) |
| Read hosted analytics | [Hosted first result](/gscdump-sdk/guides/start/hosted-first-result) |
| List Google Sites | [Direct first result](/gscdump-sdk/guides/start/direct-first-result) |

See the [direct client](/gscdump-sdk/api/direct-client) or [hosted HTTP](/gscdump-sdk/api/hosted-http) reference for the full API surface.
