# Start with gscdump CLI

Choose [cloud or local access](/gscdump-cli/guides/start/choose-access) before your first command. The choice applies to Google and Bing in the current CLI profile.

| Task | Start here |
| --- | --- |
| See your first clicks and impressions | [Run your first Search Console query](/gscdump-cli/guides/start/first-result) |
| Compare cloud and local credentials | [Choose how gscdump connects](/gscdump-cli/guides/start/choose-access) |
| Let an agent use the CLI or MCP | [Connect an agent](/gscdump-cli/guides/start/connect-an-agent) |

After the first result, [use the data](/gscdump-cli/guides/use-data). The [commands reference](/gscdump-cli/api/commands) lists every command.
