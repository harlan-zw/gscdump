# Choose how gscdump connects to Google and Bing

One saved mode applies to Google and Bing within the selected CLI profile. Choose where credentials live before running an investigation.

## Choose cloud or local

<DocsPathChoice title="Choose CLI access" first-label="Cloud" first-requirement="User API key and connected Site" first-to="/gscdump-cli/guides/start/first-result" second-label="Local" second-requirement="Google or Bing credentials on this machine" second-to="#local-access" />

| Path | Credentials | Best first check | Limits |
| --- | --- | --- | --- |
| Cloud | User API key and connections on gscdump.com | `gscdump sites --json` | Hosted access follows the Site and plan. |
| Local | Google or Bing credentials on your machine | `gscdump auth status --json` | Google write APIs need their own scopes and eligibility. |

Use `--mode cloud` or `--mode local` to override one command. The [commands reference](/gscdump-cli/api/commands) lists profile and config options.

### Cloud access

Create a user API key in [Settings](https://gscdump.com/app/settings), then connect Google on gscdump.com.

```bash
export GSCDUMP_API_KEY=gsd_user_...
gscdump auth login --mode cloud
gscdump auth status --json
gscdump sites --json
```

The saved mode applies to later commands. For Bing, connect the Site in the hosted product, then run `gscdump bing sites --json` and `gscdump bing status --site s_SITE_ID --json`.

### Local access

The default Google login opens gscdump.com for authorization. Search data calls go to Google directly. You do not need your own Google Cloud project for this read-only path.

```bash
gscdump auth login --mode local
gscdump auth status --json
gscdump sites --json
```

For your own OAuth client, set `GSC_CLIENT_ID` and `GSC_CLIENT_SECRET` first. For an existing access token, set `GSC_ACCESS_TOKEN`. For renewable credentials, set `GSC_CLIENT_ID`, `GSC_CLIENT_SECRET`, and `GSC_REFRESH_TOKEN` together. `gscdump auth status --json` identifies the active source.

A service account needs Search Console Site access. Set `GOOGLE_APPLICATION_CREDENTIALS` to its JSON key path for scheduled reads. Run `gscdump auth login --mode local --service-account ./gsc-sa.json` to check it. For a remote terminal, `gscdump auth login --mode local --no-browser` prints an authorization URL; a custom OAuth client's loopback flow may need port forwarding.

For Bing, run `gscdump bing login --mode local` and `gscdump bing sites --mode local --json`. See the [Bing reference](/gscdump-cli/api/bing) for OAuth and API key options.

## Fix access errors

If `sites` is empty, check the Google identity and the Site's Users and permissions. If cloud mode rejects the key, check the key in Settings and the selected profile. If a local grant expires, run `gscdump auth login --mode local` again. `gscdump doctor` can check configuration. Do not paste credentials into an issue or agent prompt.
