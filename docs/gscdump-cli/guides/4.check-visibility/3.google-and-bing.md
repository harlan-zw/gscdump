# Compare Google and Bing Indexing Evidence

Each Search Engine observes a URL on its own schedule and returns different fields. Keep both dates beside their evidence.

## Check both connections

Use [Choose access](/gscdump-cli/guides/start/choose-access) to connect Google and Bing in the same mode. Confirm that the URL belongs to the selected Site. Cloud Bing commands use a hosted Site ID. Local Bing commands use the exact URL printed by `bing sites`.

```bash
gscdump sites --json
gscdump bing sites --json
```

## Read Google evidence

```bash
gscdump inspect https://example.com/blog/post --site example.com --json
```

Record the inspection time, verdict, last crawl, and canonical fields when present. Absent fields mean Google did not return them. See [Indexing Evidence](/gscdump-cli/guides/check-visibility/indexing-evidence) for saved observations and quotas.

## Read Bing evidence

```bash
gscdump bing inspect https://example.com/blog/post \
  --site s_SITE_ID --mode cloud --json
```

With local Bing credentials, run:

```bash
gscdump bing inspect https://example.com/blog/post \
  --site https://example.com/ --mode local --json
```

Cloud mode reads saved Bing Indexing Evidence; local mode asks Bing directly. The [Bing reference](/gscdump-cli/api/bing) covers credentials and result errors. An unknown result does not prove absence from Bing's index.

## Compare only shared facts

| Search Engine | Observation date | Crawl evidence | Canonical or verdict | Unknown fields |
| --- | --- | --- | --- | --- |
| Google | Copy from inspection | Copy if present | Copy if present | List missing fields. |
| Bing | Copy from Bing result | Copy if present | Copy if present | List missing fields. |

Fill this table from the command results. Do not copy one Search Engine's verdict into the other row. A crawl observation does not prove indexing.

## Follow up in each Search Engine

Check the page's response, canonical, robots rules, and sitemap in each tool. Recheck after the next dated observation. If traffic also fell, use [Traffic drop](/gscdump-cli/guides/investigate-traffic/traffic-drop). More URL checks: [Check visibility](/gscdump-cli/guides/check-visibility).
