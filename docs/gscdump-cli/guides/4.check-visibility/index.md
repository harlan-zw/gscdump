# Check search visibility

Use page and query rows to check overlap. Use dated Indexing Evidence for crawl and indexing questions. Neither one proves the cause of a traffic change by itself.

| Task | Guide |
| --- | --- |
| Decide whether a new page overlaps current pages | [Check page overlap before publishing](/gscdump-cli/guides/check-visibility/page-overlap) |
| Inspect a URL and its sitemap context | [Check URL Indexing Evidence and sitemaps](/gscdump-cli/guides/check-visibility/indexing-evidence) |
| Compare dated observations across Search Engines | [Compare Google and Bing Indexing Evidence](/gscdump-cli/guides/check-visibility/google-and-bing) |

The [commands reference](/gscdump-cli/api/commands) lists URL Inspection and sitemap commands. For a click change, begin with [traffic investigations](/gscdump-cli/guides/investigate-traffic).
