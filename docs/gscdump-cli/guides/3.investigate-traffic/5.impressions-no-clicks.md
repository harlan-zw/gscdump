# Find queries with impressions but few clicks

An impression with no click is a lead for review. Search Console does not show whether an AI result caused it.

## Find queries

```bash
gscdump analyze zero-click --site example.com --period 28d --json
```

Check the date range, returned-row coverage, and minimum impression thresholds in the [Analyzer reference](/gscdump-cli/api/analyzers). An empty result can mean no candidate passed the thresholds or the data is partial.

## Check ranking and page

```bash
gscdump query --site example.com --type web \
  --query 'example query' --dimensions page,query --format table
```

Set `--start` and `--end` to the Analyzer window. Check which page has impressions, its position, and whether another page gets the same query. The [query guide](/gscdump-cli/guides/use-data/query-and-export) explains filters. For shared queries, see [page overlap](/gscdump-cli/guides/check-visibility/page-overlap).

## Review intent and appearance

Look at the current search result. Check whether the page answers the query, and whether its title describes that answer. Record device and location when they matter; search results vary. Compare CTR with the Site's observed position curve in [Low CTR](/gscdump-cli/guides/investigate-traffic/low-ctr).

## Decide whether to edit

Edit when the page misses a clear reader need or its title misstates the answer. Track the same query and page after the change. Keep the date window and search type consistent.

## Know the limit

Google Search Console does not attribute impressions or clicks to an AI result. Do not call this a GEO loss or AI Overview effect from these rows alone. Other questions: [Investigate traffic](/gscdump-cli/guides/investigate-traffic).
