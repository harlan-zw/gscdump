# Find search queries with low CTR

CTR depends on position, intent, and the search result. Start with candidates, then check each query and page.

## Find candidates

```bash
gscdump report opportunities --site example.com --period 28d --json
```

Read the striking-distance, opportunity, and zero-click Sections. Check their coverage and source. A Section with no findings can still have partial data. The [Reports reference](/gscdump-cli/api/reports) explains the result.

## Compare CTR with position

```bash
gscdump analyze ctr-curve --site example.com --period 28d --json
gscdump analyze ctr-anomaly --site example.com --period 90d --json
```

`ctr-curve` describes observed Site CTR by position. `ctr-anomaly` checks a rolling CTR baseline for each query and page. It needs more history, so use 90 days. Both Analyzers need a Store. A lower average position number means a higher ranking. See [Analyzers](/gscdump-cli/api/analyzers).

## Check the page and query

```bash
gscdump query --site example.com --type web --query 'example query' \
  --dimensions page,query --format table
```

Keep the same dates as the Report when you add `--start` and `--end`. Check impressions, clicks, CTR, and position for the page. See [Query and export](/gscdump-cli/guides/use-data/query-and-export) for filters.

## Review the search result

Open the live search result for the query. Check whether the title, description, page content, and result format match the reader's need. Search results can vary by location and device, so treat this as context.

## Read the estimate carefully

`potentialClicks` estimates clicks at a fixed target CTR. It is a heuristic, not a forecast. If the page has impressions and zero clicks, follow [Impressions, no clicks](/gscdump-cli/guides/investigate-traffic/impressions-no-clicks). Other questions: [Investigate traffic](/gscdump-cli/guides/investigate-traffic).
