# Export

## Hosted record

```bash
gscdump dump --mode hosted --site example.com --out ./export
```

Hosted mode downloads the Site's retained Google Search Console analytics, Bing search data, sitemaps, URL Inspections, and Submission Receipts. Bing files depend on preview access and a verified binding.

Use `--all-sites` to export every Hosted Site, or `--tables` to select datasets by name. The manifest lists their coverage and columns. Hosted mode writes Parquet.

With a Bearer API key, request `GET /api/partner/v1/sites/{siteId}/record-export` for the manifest. Download each listed file from `GET /api/partner/v1/sites/{siteId}/record-export/{file}`.

## Local Store

`dump` reads Google data from the Store. It never calls Google to fill a gap.
If Bing credentials exist, it also exports matching Bing data. Use `--no-bing` to skip Bing.
Every analytics row has `site` and `search_type` columns.

| `--format` | Output |
| --- | --- |
| `parquet` (default) | `<site>/<search_type>/<table>.parquet` |
| `csv`, `json`, `ndjson` | `<site>/<search_type>/<table>.<ext>`, plus a per-row `position` |
| `sqlite` | One `gscdump.sqlite` file. Dates are `YYYY-MM-DD` text |
| `duckdb` | One `gscdump.duckdb` file |

Inspections, sitemaps, and Indexing API metadata go to `<site>/<dataset>.<ext>`, or to their own tables in a database file.
`manifest.json` lists every dataset with its row count, and the same coverage that `sync --status` reports.
`--format sqlite` needs Node.js 22.13 or later.

See [export row limits](https://gscdump.com/learn-google-search-console/limits/export-row-limits) for Google’s API and interface limits.
To collect more dates before exporting, [sync historical data](/gscdump-cli/guides/use-data/build-history).
