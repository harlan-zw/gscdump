How this works

manifest.json is fetched over HTTP once (cached for the session). analyzeWithDuckDB runs as normal: the engine calls manifestStore.listLive() to get object keys for the requested date range, dataSource.uri(key) returns the HTTPS URL, and DuckDB-WASM's httpfs fetches only the bytes the query needs (Parquet footer + matching row groups).

To point this at real R2: replace baseUrl with https://<bucket>.r2.cloudflarestorage.com/<prefix> (or a signed Cloudflare Worker URL) and manifestUrl with a published manifest endpoint. Bucket CORS must allow the demo origin.
